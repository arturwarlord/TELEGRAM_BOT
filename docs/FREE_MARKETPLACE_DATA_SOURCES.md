# Бесплатные источники данных маркетплейсов

Обновлено: 2 ноября 2026 года.

## Цель

Получать для канала «Наживка» реальные карточки товаров Wildberries, Ozon, Яндекс Маркета и других маркетплейсов без расходов на сервисы или запросы. Публикация должна содержать прямой URL конкретной карточки, а не категорию, поиск, купон или промежуточный редирект.

## Вывод проверки

На дату проверки не найден бесплатный официальный API, который одновременно:
- открыт любому стороннему разработчику без кабинета продавца и токена;
- позволяет искать весь публичный ассортимент маркетплейса и находить товары со скидкой;
- разрешает автоматическое получение и последующее использование данных/изображений в публичном Telegram-канале.

Не подменять этот вывод утверждениями о том, что «парсер работает». Техническая доступность сайта или неофициального endpoint не означает разрешение на массовый сбор и перепубликацию данных.

## Площадки

| Площадка | Что доступно бесплатно | Почему пока не подключаем общий каталог |
|---|---|---|
| Wildberries | Официальный WB API для собственных магазинов продавца; требуется токен магазина | API управляет ассортиментом и данными конкретного магазина. Публичный официальный API общего каталога для стороннего канала не подтверждён. |
| Ozon | Официальные Seller API и отдельные коммерческие/аналитические доступы | Пользовательское соглашение прямо запрещает использовать ботов и парсеры в отношении сервисов Ozon и обходить ограничения. Не собирать сайт или его внутренние endpoints автоматически. |
| Яндекс Маркет | Partner API бесплатен | Официальная документация описывает работу с магазинами/кампаниями продавца, их товарами, ценами и остатками, а не поиск всего каталога для стороннего канала. |
| Мегамаркет | API и интеграции для продавцов | Нужны разрешённый доступ и данные кабинета магазина; общего открытого каталожного API не подтверждено. |
| AliExpress | Есть API/партнёрские механизмы | Исключены, если требуют affiliate/deep links или редиректы. Возвращаться к ним можно только при наличии бесплатного официального источника прямых карточек и разрешения на использование данных. |
| Lamoda, Детский мир и другие | Проверяются отдельно | Подключать только после подтверждения бесплатного разрешённого фида/API, прямых карточек и пригодных полей товара. |

## Почему не используем найденный неофициальный парсер

Найден открытый MIT-проект [ru-marketplace-mcp](https://github.com/Vladimir-Human/ru-marketplace-mcp), технически умеющий читать несколько маркетплейсов. Однако документация самого проекта предупреждает, что условия площадок обычно запрещают неофициальный парсинг, а результат не предназначен для перепубликации или массового сбора. Некоторые его коннекторы требуют локальный Chrome, вход пользователя или российский домашний IP. Поэтому такой парсер не является приемлемой основой автоматической публикации из GitHub Actions.

## Принимаемые бесплатные способы

### 1. Разрешённый фид продавца или поставщика

Продавец/поставщик может предоставить доступ к собственному YML/XML/JSON-фиду и подтвердить право на его автоматическую обработку и использование изображений. В фиде должно быть отдельное поле с прямой ссылкой на карточку именно маркетплейса. Фид магазина, где ссылка ведёт на его собственный сайт, не считается карточкой маркетплейса.

В проекте уже поддерживаются XML/RSS/Atom и JSON. Для нестандартных полей можно задать fields, например:

~~~json
{
  "type": "xml",
  "fields": {
    "title": ["name", "model"],
    "product_url": ["marketplace_url", "product_url", "url"],
    "image_url": ["picture", "image", "photo"],
    "price": ["price", "sale_price"],
    "old_price": ["oldprice", "old_price"],
    "external_id": ["sku", "vendorCode", "offer_id"]
  }
}
~~~

Это только пример сопоставления полей, не готовая ссылка на фид. Не добавлять фиктивные URL и не включать пример в production-конфигурацию.

### 2. Официальный API магазина с добровольно предоставленным доступом

Если конкретный продавец предоставит токен и разрешит использовать его товары для канала, можно подключить его собственный ассортимент. Не просить и не хранить токены без необходимости; использовать GitHub Actions Secrets. Такой доступ не означает разрешения на сбор товаров других продавцов.

### 3. Публичный фид от правообладателя данных

Можно подключить бесплатный публичный фид/экспорт от поставщика данных только при подтверждённом разрешении на коммерческое использование, публикацию карточек и изображений. Наличие открытого файла без лицензии само по себе не является разрешением.

## Жёсткие критерии допуска источника

Источник можно включить в production только если все условия выполнены:

1. Стоимость действительно равна 0 €: нет платной подписки, тарификации по запросам, обязательной карты или платного тестового периода.
2. Доступ официально разрешён владельцем фида/API; никакого обхода CAPTCHA, антибота, блокировок, логина или rate limit.
3. Каждая запись содержит название, прямой URL карточки маркетплейса, цену и устойчивый ID/SKU.
4. Изображение предоставлено источником с правом использования либо есть явное разрешение на публикацию.
5. Старая цена берётся только из явного поля источника; если её нет, бот не выдумывает скидку.
6. URL ведёт на карточку товара, без affiliate-параметров и redirect-обёрток.
7. Товар и цена проходят несколько read-only проверок; дубли и снятые с продажи товары отбрасываются.
8. Сначала источник работает в диагностическом режиме. Включение публикации — только после успешной проверки.

## Текущий статус в репозитории

- Wildberries: HTML-кандидаты выключены после HTTP 498 от GitHub Actions; обходить ограничения нельзя.
- Ozon: HTML-кандидаты выключены после редиректов из runner; отдельно действует запрет пользовательского соглашения на ботов/парсеры.
- Яндекс Маркет и Мегамаркет: карточки не включены в production без подтверждённого бесплатного разрешённого общего фида.
- Ни один общий каталог маркетплейса не включён в автоматическую публикацию на основании неофициального парсинга.
- Существующий импортёр YML/XML/JSON готов принимать реальные разрешённые фиды, когда появится их URL/доступ.

## Следующий практический шаг

Искать не «ещё один парсер», а владельцев бесплатных фидов с явным полем marketplace product URL и разрешением на публичное использование. Параллельно можно подключать отдельные магазины продавцов, если они добровольно дадут доступ к своему ассортименту. До появления таких данных не обещать массовый автоматический поток WB/Ozon/Яндекс Маркета.
